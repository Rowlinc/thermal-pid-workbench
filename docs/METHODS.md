# 方法、比较范围和结果解释

对象近似为 `G(s)=K exp(-θs)/(τs+1)`。阶跃辨识使用输出和温度变化量估计 K，并根据 5%/63.2% 响应交点估计 τ/θ，校验阶跃基线、时间单位和拟合误差。它适用于可由稳定、自平衡、单输入单输出 FOPDT 近似的局部工况；强非线性、耦合、逆响应、积分或不稳定对象需要更合适的模型/算法。

这次新增的泛化能力，是对象、任务、单位、控制器及判据可配置，并有明确扩展接口；不是假定一个 FOPDT 可以代表所有化工过程。

## 参数公式

| 方法 | Kp | Ti | Td |
|---|---|---|---|
| Z-N PID | `1.2τ/(Kθ)` | `2θ` | `0.5θ` |
| Z-N PI | `0.9τ/(Kθ)` | `3.33θ` | `0` |
| SIMC PI | `τ/[K(λ+θ)]` | `min(τ,4(λ+θ))` | `0` |

并联式换算：Ki=Kp/Ti、Kd=Kp·Td。Z-N 要求 θ>0；SIMC 允许 θ=0 且 λ>0。本项目默认 λ=`max(θ,τ/3)`，是本项目用于离线起点的较缓和选择；它不是论文中普遍推荐值的原样复制。
SIMC 来源见 [Skogestad 的论文及公式说明](https://skoge.folk.ntnu.no/publications/2003/tuningPID/README.html)；有关较缓和整定的讨论见 [作者说明](https://skoge.folk.ntnu.no/publications/2003/tuningPID/smooth_tunings/)。IMC 只用于说明 SIMC 的理论背景，没有独立的 IMC 算法候选。

## 程序级约束

原项目已有 `pid_safety.py`、历史最佳参数和回滚机制，因此原项目不是完全依赖 Prompt 保证调参安全。本项目保留这些机制，并对 Z-N、SIMC 和 LLM 使用同一确定性参数检查。报告区分原建议与参数接受或拒绝状态，超限整组拒绝，不自动裁剪，最终建议也再次检查相对起始 PID 的增幅。

新统一工作流采用完整任务重跑评价，以使 LLM 各轮条件可比较；遗留 `tuning_pipeline.py` / 原引擎继续保留其连续窗口流程。两者的停止和评分口径不同，不能混用结果。

## 三组代表什么

| 组别 | 初始化 | 后续 |
|---|---|---|
| original_zn | 原始 ZIP 中的辨识函数 + Z-N PID | 相同护栏、控制器、模型、判据及可选 LLM |
| corrected_zn | 修正辨识/提供的模型 + Z-N PID | 相同流程 |
| selected | 修正辨识/提供的模型 + 候选 Z-N/SIMC 中择优 | 相同流程 |

这是隔离辨识/初始化改动的对照，不是把整个原版程序在不同默认值下运行后直接比较。`reference/original_system_id.py` 保留原文件，SHA-256 可核验。使用已知模型时，original_zn 从该模型生成的合成阶跃做原辨识；其他组使用提供的 K/τ/θ。CSV 模式使用同一份历史数据，原辨识仍保留其原来的时间处理逻辑。某算法算不出参数时，报告会记录不可用原因，不编造结果。

选择规则首先要求所有门槛达标，再依次比较 IAE、输出 TV、调节时间。无合格组时可以显示诊断曲线，`pid.json` 的参数为 null，使用模式拒绝写入。

selected 并不保证选择 SIMC。护栏可能把多个公式结果裁成相同参数，执行器饱和也可能导致响应接近。应同时查看候选参数、护栏记录、曲线和指标。默认配置关闭 LLM，便于复现实验；开启后应记录模型名、轮数和是否回滚，单次 LLM 随机结果不能证明统计优势。

## 怎么验证是否比原项目的初始化更好

先运行默认任务，比较合格性、IAE、稳态误差、调节时间和输出变化。然后用不同 K/τ/θ、目标温差、采样周期、输出范围、噪声、模型增益偏差和扰动重复运行；每次保留配置与结果。最后用未参与调参的历史/模型或实物平台验证泛化。

如果 selected 只在同一模型上选最优，它证明的是“当前候选集合和模型下择优有效”，而不是对真实化工过程的独立验证。公开结论应报告失败案例、约束条件和测试范围。真正过程安全仍由现场 DCS/PLC/SIS 等独立保护负责。
