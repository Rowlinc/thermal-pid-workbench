从这里开始

  1. 选择一个示例，或填写被控量、单位和目标。
  2. 选择对象来源：已知参数、历史 CSV、离线模型辨识，或自定义模型＋用户 PID。
  3. 填写执行器范围与合格要求。模型、数据、目标和误差使用同一单位。
  4. 需要大模型时开启 LLM 并保存 API 密钥；否则关闭即可。
  5. 点击开始运行。结果先看是否合格，再看响应、IAE、末段误差和控制输出变化。
  6. 查看报告、导出 PID 或打开结果目录。设备接入前配置协议和读写语义。

支持范围

这是单回路 PID 工作台。FOPDT 是一阶惯性加滞后；积分模型适合已知积分动力学的对象。模型类型与整定公式必须匹配。CSV 当前只自动辨识 FOPDT；复杂对象通过自定义模型或原 Simulink 流程接入。提供一个目标值并不足以描述设备。

参数形式

内部使用秒制并联式非负幅值 p/i/d，方向由 K 决定；导出根据所选并联式 Kp/Ki/Kd 或理想式 Kp/Ti/Td 和秒／分钟正确换算。不同被控量的增益单位也不同，不能直接搬用另一对象参数。

三组对比

original_zn：原辨识算法＋Z-N；corrected_zn：修正辨识＋Z-N；selected：在同一模型上比较适用候选后选优。启用 LLM 时，各组从自己的初始参数继续调优。原算法组是统一仿真条件下的算法基线，并非整个旧项目的性能结论。

模型文件与硬件

Python 自定义模型在本机执行，应由用户确认来源。Simulink 需要安装 MATLAB/Simulink 和兼容 Python Engine。通用 TCP/串口网关与原 CSV 串口协议是不同接入方式；原项目硬件配置全部保留。应用不内置任意厂商 PLC/DCS 驱动。

保存位置

每次结果独立保存；配置和 CSV 保存在本机；API 密钥不会导出到方案或公共配置。需要 API 时会联网，仿真与参数检查在本机进行。

保护机制

数值和范围检查、LLM 增幅检查、完整仿真评价、最佳参数保留与回滚继续生效。实际过程保护由现场 DCS/PLC/SIS 等既有体系负责；仿真达标不等于装置已完成投运验证。
